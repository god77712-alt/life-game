플레이어의 실제 방 사진이 도트 게임이 되고, AI 디렉터가 매일의 행동에서 회피하는 것과 원하는 것을 읽어 그 사람만의 마지막 장소를 짓는다.
거기 도착하는 순간 게임 속 모든 행동이 0점이 된다. 점수가 붙는 건 하나뿐 — 현실에서 진짜로 해낸 일의 사진.
게임을 그만두게 만드는 것이 승리 조건인 게임.

2. 게임의 목표

이 게임의 목표는 높은 점수가 아니라 게임을 끝내는 것이다.

  • 게임은 처음에 플레이어에게 점수를 후하게 준다 — 이불을 개고, 창문을 열고, 밖에 나가고, 사람과 말을 섞는 모든 행동에 점수가 붙는다.
  • AI가 플레이어의 회피 패턴과 숨은 바람을 각각 가설로 세우고, 그것을 검증할 사건을 매일 편성한다.
  • 두 가설이 모두 확정되면 그 사람만의 골 맵이 열린다. 거기에는 플레이어와 같은 회피를 가진 인물(거울)이 서 있다.
  • 플레이어는 그를 응원한다. 남에게 해주는 말이라 쉽게 나오지만, 그 말은 결국 자기 자신에게 하는 말이다.
  • 그 대화가 끝나면 다음 날 아침부터 게임 속 모든 행동이 +0점이 된다. (붕괴)
  • 0점짜리 하루를 통째로 살아본 다음 날, 게임은 처음으로 현실에서 무언가를 해오라고 요구한다. 실제로 하고 사진을 올리면 +100점 — 이 게임에서 점수가 붙는 마지막이자 유일한 행동이다.

메시지를 대사로 말하지 않는다. 시스템(무점수 붕괴)이 스스로 말하게 한다.

3. 조작

이동← ↑ ↓ → 또는 WASD — 타일 스냅 4방향  ·  터치: 가고 싶은 칸을 누른다
행동Space 키 하나뿐  ·  터치: 바라보는 대상을 누른다
대화↑ ↓ 선택 · Space 확정. 결정적 장면에서는 자유 입력으로 직접 쓸 수 있다
디버그G — 격자·충돌·점수 기회 표시 (개발용)

행동 키는 하나다. 무엇을 하는지는 바라보는 대상과 그 상태가 정한다. 같은 침대라도 이불이 헝클어져 있으면 이불 개기, 개어져 있으면 자기가 된다. 버튼을 여러 개 두면 이 설계가 무너지므로 두지 않았다.

4. 규칙

시간

1 실제초 = 3 게임분      ·      하루는 침대에서 잘 때만 끝난다
자정은 하루를 끝내지 않는다 — 시계가 24:00을 넘어 계속 간다
안 자면 점수도 안 쌓이고 정산도 안 돈다 → 벌이 아니라 자야 할 이유 (감점 없음)

점수 — 멀리 갈수록 크다

L0 몸이불 개기 / 물 마시기 / 씻기+10
L1 방청소 / 창문 열기 / 커튼 걷기+15
L2 문 밖현관 나가기 / 편의점 / 산책+30
L3 사람NPC 대화 / 초대 수락+50
L4 확장확장 수락 / 골 맵 도달+80
붕괴 이후위의 전부+0
R 현실실제로 하고 사진 인증+100
  • 감점이 없다. 처벌도 없다. 오직 가점만 있으며, 현실 인증에 실패해도 깎이지 않는다.
  • 같은 행동은 하루 1회만 점수. 날이 바뀌면 방도 원상복구되고 점수만 누적된다.
  • 누적 점수는 절대 깎이지 않는다. 붕괴날의 오늘 +0은 그 위에서만 성립한다.

사람 · 대화

  • 고정 NPC와 고정 대사가 없다. 누가 어디 사는지만 정해져 있고, 무슨 말을 하는지는 매번 AI가 쓴다.
  • 대화는 선택지를 골라도 끝나지 않는다 — 고른 말을 상대에게 건네고 계속 이어진다. NPC도 대화를 끝낼 수 있다.
  • 호감도는 말을 섞는 것만으로는 오르지 않는다. 자기 말을 직접 쓰거나(+3), 부탁을 들어주거나 필요한 걸 건넸을 때(+10)만 오른다.
  • NPC가 말끝에 흘린 말("요즘 커피를 하도 마셔서")은 화면에 표시되지 않는다. 듣고 기억해 사다 주면 건넬 수 있다.

종료 조건

  1. 회피·바람 두 가설이 모두 confirmed → 골 맵이 열린다
  2. 골 맵의 거울 인물과 대화를 마친다 → 다음 기상부터 모든 행동 +0 (붕괴)
  3. 붕괴 하루가 지나면 현실 인증 요구 → 실제로 하고 사진 업로드 → +100
  4. 엔딩 — 게임 안에서 번 점수와 현실에서 번 점수를 나란히 보여주고 끝난다

총 일수는 정해져 있지 않다. 엔딩 날짜를 미리 고정하지 않으며, 골 맵은 가설이 확정될 때만 열린다.

5. 실행 방법

심사자용 — 웹 (설치 없음)

https://life-game-jqh6.onrender.com  ← 링크를 열면 끝

타이틀 → [처음부터] → 시작 설문 9문항 → 방 사진(선택) → 플레이

방 사진은 선택입니다. 카메라가 없거나 방을 보여주고 싶지 않으면 [건너뛰기]를 누르면 준비된 방으로 시작합니다. 올린 사진은 인식 즉시 폐기되며 어디에도 저장하지 않습니다.

로컬 실행 (소스에서)

git clone https://github.com/god77712-alt/life-game.git
cd life-game
npm install
cp .env.example .env      # ANTHROPIC_API_KEY 를 채운다
npm start                 # http://localhost:5173  — 정적 파일 + API 프록시 한 서버
npm test                  # 테스트 300개

API 키가 없어도 실행됩니다 — 방 사진 입력만 비활성화되고 나머지는 준비된 데이터로 동작합니다. Node.js 20 이상이 필요하며, 별도 유료 라이선스나 빌드 도구는 필요하지 않습니다(번들러 없음, ES 모듈 직접 서빙).

6. 개인정보 취급

  • 방 사진은 저장하지 않는다. 브라우저에서 축소해 서버로 보내고, 서버는 인식 모델에 넘긴 뒤 즉시 버린다. 디스크에 쓰지 않는다.
  • 현실 인증 사진도 같다. 확인하는 데만 쓰고 버린다.
  • API 키는 서버 프로세스 밖으로 나가지 않는다. 클라이언트에 노출되지 않는다.
  • 진행 상황은 플레이어 브라우저의 localStorage에만 남는다. 서버는 플레이어를 식별하지 않는다.
