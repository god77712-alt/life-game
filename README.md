# 힘을 내 히키코모리 (가칭)

> NHN NAN 2026 해커톤 사전 과제 · 개인 참가 · 마감 2026-08-10

플레이어의 **실제 방 사진**이 도트 게임이 된다.
AI 디렉터가 매일의 행동에서 **이 사람의 입이 언제 열리는가**를 읽고, 가설을 세우고, 그것을 검증할 무대를 짠다.
가설이 확정되면 그 사람만의 마지막 장소가 생긴다.
**끝나는 날은 정해져 있지 않다** — 결과가 나올 때까지 계속된다.

거기 도착하는 순간, **게임 속 모든 행동이 0점이 된다.**

점수가 붙는 건 하나뿐이다 — 현실에서 진짜로 이불을 갠 사진.

**게임을 그만두게 만드는 것이 승리 조건인 게임.**
메시지는 말이 아니라 시스템으로 전달한다.

## 실행

```bash
npm install
cp .env.example .env      # ANTHROPIC_API_KEY 채우기
npm start                 # http://localhost:5173
npm test
```

키가 없어도 **방 사진 입력만 막히고 나머지는 전부 돈다** (준비된 목 데이터로 동작).
`?skip`을 붙이면 설문을 건너뛰고 바로 방으로 들어간다 — 개발용.

```
이동      ← ↑ ↓ →  또는  WASD
상호작용   Space   ← 키는 이것 하나. 바라보는 대상(+ 그 상태)이 행동을 정한다
디버그     G   격자·충돌·점수 기회
```

## AI 10개가 역할을 나눠 맡는다

프롬프트는 전부 [`prompts/*.md`](prompts)에 있고 **서버가 그 파일을 직접 읽는다.** 코드에 복붙하지 않는다.

| AI | 역할 | 언제 | 일부러 안 주는 것 |
|---|---|---|---|
| `casting` | 설문 → 세계·등장인물 | 시작 1회 | **욕망·회피 필드가 스키마에 없다.** 가설은 행동에서만 나온다 |
| `room-vision` | 방 사진 → 오브젝트 JSON | 사진 입력 시 | — (사진은 인식 후 즉시 폐기) |
| `referee` | **어제의 예측 vs 오늘의 결과 판정** | 매일 | **현재 confidence.** 보면 마저 올려주고 싶어진다 |
| `analyst` | **누구에게 · 무엇을 매개로 · 언제 열리는가** | 매일 | 점수를 매길 권한. 문장을 좁히는 게 일이다 |
| `director` | 내일의 무대·이벤트 편성 | 매일 | 원본 대화 전문. 판정된 표만 본다 |
| `writer` | 편성 1건 → 대사와 선택지 | 접촉 시 실시간 | 가설 테이블. 대사가 의도를 흘리면 안 된다 |
| `goal-map` | confirmed 가설 → 그 사람만의 마지막 장소 | 게임당 1회 | — |
| `mirror` | 거기 있는 사람 — **플레이어와 같은 모양** | 마지막 장면 | — |
| `reality` | **실제로 한 일의 사진 확인** | 붕괴 다음 날 1회 | 가설·점수. 사진과 한 줄뿐 |
| `npc-reply` | 직접 친 말에 대한 답 | 채팅 중 실시간 | 가설 테이블 |

### 세우는 쪽과 채점하는 쪽을 나눴다

처음에는 `analyst`가 가설을 세우면서 그 가설의 confidence도 스스로 매겼다.
**자기 숙제를 자기가 채점하는 구조라 반증이 불가능했다.**

지금은 이렇다:

```
디렉터가 어제 watch(예측)를 미리 쓴다          ← 사후에 기준을 못 바꾼다
        ↓
referee ┐  두 AI는 서로의 출력을 보지 않는다
analyst ┘  (독립적이어야 채점이 채점으로 남는다)
        ↓
코드가 confidence를 움직인다                   ← 여기가 유일한 출처
  supported +0.10 · 검증 +1
  contradicted −0.15        ← 반박이 지지보다 무겁다
  no_data 변화 없음         ← 증거의 부재는 부재의 증거가 아니다
```

**문턱 판정도 코드가 한다.** 다섯 조건 전부 상수다 ([`server/hypothesis.mjs`](server/hypothesis.mjs)) —
모델에게 맡기면 매 호출마다 흔들리고, 같은 사람이 같은 플레이를 해도 다른 날 끝난다.

```
confidence ≥ 0.7  ·  검증 2회  ·  3겹 신호
+ 가설이 상대를 지목할 것              ← 혼자 하는 일은 이 게임의 답이 아니다
+ 그 상대에게 실제로 자기 얘기를 한 적이 있을 것
```

마지막 둘이 없던 시절, 확정된 가설은 '고양이에게 밥 주기'였다. 혼자 하는 일이다.
골 맵은 거기 맞춰 사람을 지웠다 — **문턱을 없애랬더니 사람을 없앤 것이다.**

**끝나는 날은 정해두지 않았다.** 며칠이 걸릴지는 설계값이 아니라 이벤트 품질의 결과다.

### 제 기능을 하는지 코드로 검사한다

그럴듯한 글은 읽으면 다 맞는 말 같다. 그래서 글이 아니라 숫자로 묻는다.

```bash
node scripts/simulate.mjs 10          # 숨은 선호를 심어놓고 AI가 찾아내는지
node scripts/audit.mjs a              # 적응·표적성·감쇠·수렴·정체·판정 6가지 검사
node scripts/audit.mjs --diff a b     # ★ 성향이 정반대인 두 사람이 다른 결론으로 가는가
```

마지막 것이 결정적이다 — 정반대인 사람에게도 같은 결론이 나오면 **읽는 게 아니라 외운 것**이다.

## 배포

Node 프로세스 하나만 띄우면 된다. 정적 파일과 API 프록시가 같은 서버라 CORS도 없다.

[`render.yaml`](render.yaml)이 들어 있어서 Render에 저장소를 연결하면 알아서 뜬다.
**키는 저장소에 없다** — Render 대시보드 Environment에 직접 넣는다.

```
git push  →  Render 감지  →  자동 배포 (2~3분)
```

정산은 AI를 4~7개 돌려 95초~5분이 걸리므로, 서버가 작업 id만 즉시 주고
클라이언트가 `/api/job/:id`로 물어본다. 요청 하나로 붙들면 중간 프록시가 먼저 끊는다.

## 개인정보

- **방 사진은 저장하지 않는다.** 브라우저가 축소해 보내고, 서버는 함수 스코프 안에서만 들고
  Claude에 넘긴 뒤 버린다. 디스크에 쓰지 않고 로그에도 남기지 않는다
- API 키는 서버 프로세스 밖으로 나가지 않는다. 클라이언트 번들에 없다
- 플레이어가 직접 친 문장은 **요약하지 않고 원문 그대로** 보관한다.
  그 사람의 말투가 거기 있고, 마지막 장면의 거울이 그것으로 만들어진다
